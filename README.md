# GODANキーボードオーバーレイ（VR）

SteamVRのオーバーレイとして、VRの中にGODAN配列のキーボードやPCの画面を出すアプリです。キーボードで打った文章はVRChatのChatboxに出ます。設定を変えると、TTSツール（vrc_osc.py）に送って読み上げることもできます。

## 起動

VRChatのOSCを有効にしておきます（アクションメニューの「Options」→「OSC」→「Enabled」）。

SteamVRを起動してから`run.bat`を実行します。`run.bat`が先でも、SteamVRが立ち上がるのを待ってから接続する作りです。.NETのインストールは要りません。

SteamVRと一緒に自動で起動させるときは、SteamVRを起動した状態で`register_steamvr.bat`を一度実行します。登録を外すときは`unregister_steamvr.bat`を実行します。

### TTSで読み上げる

設定ファイル（`app\overlay_config.json`）の`output.sendTo`を`"tts"`にすると、「送信」した文章をTTSツールのvrc_osc.pyへ送って読み上げます。オーバーレイを起動し直すと切り替わります。読み上げるときは、vrc_osc.pyとEasy-Irodori-TTSも起動しておきます。

### 管理者権限

Steamを管理者として起動していると、Steamから起動したVRChatとSteamVRも管理者権限で動きます。このとき一般の権限のアプリはSteamVRに接続できず、無理に接続しようとするとSteamVRが新しいアプリを受け付けなくなります。そのためbatファイルはすべて管理者として起動し、UACの確認が出ます。`register_steamvr.bat`で自動起動を登録しておくと、SteamVRが同じ権限で起動するので確認は出ません。

パネルは、出るときに少し小さい所から大きくなりながら浮かび上がり、消えるときはすっと薄くなって消えます。メニューの設定タブで切ったり長さを変えたりできます。

## 操作

| 操作 | ボタン（Quest、Oculus Touch） |
|---|---|
| 時計の表示と非表示 | Xを2回押す |
| キーを押す、クリック | トリガー |
| フリック | トリガーを押したままレーザーを上下左右に動かして離す |
| パネルを動かす | パネルにレーザーを当ててグリップでつかむ |
| 大きさを変える | 両手のグリップで同じパネルをつかみ、手の間を広げたり狭めたりする |
| つかんだまま遠近と大きさ | スティックの上下と左右 |
| PCの画面の右クリック | 右手のA（左手ならX）を押しながらトリガー |
| PCの画面のスクロール | 画面にレーザーを当ててトリガーを押したまま動かす（タッチ画面と同じ）か、スティック |

ボタンの割り当ては、SteamVRのコントローラー設定でアプリ名「GODAN Overlay」を選ぶと変えられます。右クリックのボタンは「右クリック（押しながらトリガー）」の項目です。SteamVRで割り当てを一度保存すると、そちらが優先され、このアプリが用意した割り当ては使われなくなります。

### 時計

上の段は再生中の曲の操作（前の曲、再生と一時停止、次の曲）と全体の音量です。下の段で各パネルを出し入れします。「手前へ」を押すと、表示中のパネルが目の前に戻ります。

ほかのパネルは時計と一緒に消え、「ロック」を押したパネルだけが残ります。時計を出すと、消したパネルは、消したときの頭の位置から見た方角と距離のまま、今の頭の位置に合わせて戻り、自分の方を向きます。消すときにどちらを向いていたかは関係ありません。手前への傾きは元のままです。プレイスペースを動かしてずれていても、呼び出せば元の見え方に戻ります。設定で時計を消さないようにすると、Xの2回押しではほかのパネルだけが消えたり戻ったりします。時計の位置がずれていたら、もう片方の手のレーザーを時計に当て、グリップでつかんで動かします。離した位置は保存されます。

### メニュー

時計の「メニュー」で開きます。タブは4つです。

| タブ | 内容 |
|---|---|
| パネル | 開いているパネルの一覧。表示の切り替え、HUD（視界に固定）、曲面、閉じる |
| ウィンドウ | PCで開いているウィンドウの一覧。押すとそのウィンドウを映すパネルが増える |
| 音量 | 全体とアプリごとの音量、ミュート |
| 設定 | よく変える設定。押すとその場で効き、設定ファイルにも保存される |

曲面は押すたびに「平面、曲面1、曲面2、曲面3」の順に変わります。HUDにしたパネルは、そのときの見え方のまま頭についてきます。

### キーボード

配列はスマホと同じかなのフリック入力、GODAN配列、日本語配列のQWERTYの3つです。左上のボタンで切り替えます。GODANとフリック入力では、キーの端の小さい文字がフリック先です。

フリック入力では、トリガーを押したままレーザーを上下左右に動かして離すと、その方向の文字が入ります。どちらの配列も、何も割り当てのない方向へ動いてしまったときは、キーをそのまま押したことになります。「゛゜小」は最後の文字を小文字、濁点、半濁点の順に切り替えます。

途中の字を直すときは、入力欄の文字をレーザーで押すとそこへカーソルが移ります。押したまま左右に動かすと位置を調整でき、そこで打つと文字が入り、削除のキーでカーソルの前の字が消えます。

トリガーを引いた瞬間は手が動いて狙いがずれやすいので、引く少し前（0.06秒）にレーザーが指していた所を押したことにしています。

GODAN配列は、子音と母音のキーを順に押して打つ配列です。「ん」は`N`を2回押します。「んに」なら`N N N I`です。各キーを下に強めにフリックすると数字が入ります（電話のテンキーと同じ並びで、`A`が1、`Y`が9、`N`が0）。トリガーを引くとレーザーが下にぶれやすいので、キーの外まで引っ張らないと数字にはならず、軽く下にずれただけならキーを押したことになります。`Y`の左右で（）、`W`の左右で「」、`N`の上で…が入ります。

下線の付いた部分がまだ確定していない文字で、変換するのはこの部分だけです。打っている途中から変換候補が出て、候補を押すとその部分が確定し、続きを打てます。「変換」を押すと文節ごとに変換し、そのときの上の段は文節、下の段は候補です。「確定」で確定し、確定していない文字がないときに「変換」を押すと全角スペースが入ります。

「送信」を押すと、文章がVRChatのChatboxに出ます。送信先をTTSにしているときは、vrc_osc.pyに送って読み上げ、Chatboxにも出します。vrc_osc.pyが起動していないときはChatboxにだけ送ります。「出力」をPCにすると、送信の代わりにPCで選んでいるウィンドウへ文字を入力します。PCへの出力では、こちらでは変換せずに、打ったキーをそのままPCへ送ります。変換はPCのIMEが行い、「変換」はSpace、「送信」はEnter、削除のキーはBackspace、ヘッダーの「半/全」はIMEの切り替えになります。フリック入力の「か」はKとAのキーとして送ります。

### QWERTY

キーボードの左上のボタンで3つ目の配列にすると、日本語（JIS）配列のQWERTYになり、パネルが横に広がります。ファンクションキーとCapsLockはなく、CapsLockの所までTabが大きくなっています。キーは押した瞬間に入り、削除のキー、Del、矢印は押し続けると繰り返します。

Shift、Ctrl、Alt、Winは、押すと光り、次に押したキーと組み合わせて送ります。Ctrlを押してからCを押すとCtrl+Cです。Winを2回押すとスタートメニューが開きます。

出力がPCのときは、本物のキーボードと同じくキーをそのまま送り、日本語はPCのIMEで打ちます。それ以外のときはローマ字入力になり、Spaceと変換のキーで変換、Enterで確定し、確定するものがないときのEnterで送信します。

### PCの画面

デスクトップ全体を映すパネルと、ウィンドウを1つずつ映すパネルがあり、操作は同じです。レーザーの位置にマウスカーソルが動き、トリガーはWindowsのタッチとして届きます。タッチ画面と同じなので、タップでクリック、押したまま動かすとスクロール、長押しで右クリックです。両手のレーザーで同じ画面を押して広げると、ピンチで拡大できるアプリもあります。両手のレーザーを当てているときは、最後にクリックした方の手にマウスが付いていきます。ウィンドウのパネルは、押した所でそのウィンドウが一番手前になっていなければ、そのウィンドウを選んで手前に出してからクリックを送ります。「常に手前」の別のウィンドウが重なっていて手前に出せないときは、そのウィンドウへクリックを直接送ります。

右クリックは、右手のAか左手のXを押しながらトリガーを引きます。どちらの手のトリガーでも効き、タッチではなくマウスの右ボタンとして届きます。Xは時計の2回押しと兼用で、押しながらトリガーを引いたときは2回押しに数えません。モニターが2枚以上あると、デスクトップのパネルの下のバーに、映すモニターの切り替えと「モニター追加」が出ます。「モニター追加」を押すと、まだ出していないモニターのパネルが隣に増えます。増やしたパネルは「閉じる」で消せます。別のパネルが映しているモニターに切り替えると、そのパネルと映すモニターが入れ替わります。

PCのマウスカーソルは、画面のパネルの上に少し大きめに描きます。

画面に動きがないと、開いた直後は黒いままのことがあります。何か動けば映ります。最小化したウィンドウは映りません。

### Windowsの通知

Discordなどの通知が来ると、時計の上に8秒だけ表示します。表示する場所は、メニューの設定タブの「通知」で「時計、視界、オフ」から選びます。視界にした場合の表示は、視界の下に5秒だけです。

## 設定ファイル

設定は`app\overlay_config.json`にあり、初回の起動時に作られます。ファイルを書き換えた場合は、次の起動から反映されます。メニューの設定タブにある項目は、VRの中で変えるとその場で効きます。ログは`app\overlay.log`に出ます。

| 項目 | 内容 |
|---|---|
| `watch.hand` | 時計を付ける手。`"right"`か`"left"` |
| `watch.doublePressSeconds` | 2回押しとみなす間隔（秒） |
| `watch.alwaysShow` | 時計を消さないか。`true`にすると、2回押しでほかのパネルだけを出し入れする |
| `watch.restoreRelativePosition` | 呼び出したパネルを、頭の位置に合わせて動かし、自分の方を向けて戻すか。`false`なら消す前と同じ場所と向きに戻る |
| `keyboard.widthMeters` | キーボードの幅（m） |
| `keyboard.defaultOutput` | 起動時の出力先。`"chatbox"`か`"pc"` |
| `keyboard.flickThreshold` | フリックと判定する移動量。キー幅に対する割合 |
| `keyboard.numberFlickThreshold` | 数字のフリックと判定する移動量。キー幅に対する割合 |
| `keyboard.style` | 配列。`"godan"`、`"flick"`、`"qwerty"` |
| `keyboard.flickLayout` | フリック入力の配列。`grid`がキーの並び、`flicks`がフリック先 |
| `keyboard.layout` | GODAN配列。書き方は`flickLayout`と同じ |
| `desktop.monitorIndex` | 映すモニター |
| `desktop.maxFps` | PCの画面を更新する回数（毎秒） |
| `desktop.maxTextureWidth` | VRへ送る画像の最大の幅（px） |
| `desktop.showCursor` | マウスカーソルを画面のパネルに描くか |
| `desktop.cursorScale` | 描くカーソルの大きさ（PCでの大きさに対する倍率） |
| `desktop.touchMode` | トリガーをタッチとして送るか。`false`にするとマウスの左ボタンになる |
| `output.sendTo` | 「送信」の送り先。`"chatbox"`（Chatboxへ直接）か`"tts"`（vrc_osc.pyへ送って読み上げ） |
| `output.ttsServerUrl` | vrc_osc.pyのURL |
| `output.oscFallback` | vrc_osc.pyに届かないとき、Chatboxへ直接送るか |
| `output.oscHost` | VRChatのOSCの送り先 |
| `output.oscPort` | VRChatのOSCのポート |
| `converter.engine` | `"google"`（Google日本語入力のWeb API）か`"none"` |
| `input.blockGameInputWhilePointing` | パネルを指している間、VRChatにボタンの入力を渡さないか |
| `input.pressStabilizeMs` | トリガーを引いた瞬間のブレを打ち消す時間（ミリ秒）。`0`で無効 |
| `input.rightClickWithButton` | 右クリックのボタンを押しながらトリガーで右クリックにするか |
| `input.laserWidthMeters` | レーザーの太さ（m） |
| `notifications.enabled` | Windowsの通知を読み取るか |
| `notifications.display` | 通知を出す場所。`"watch"`（時計）、`"hud"`（視界）、`"off"` |
| `notifications.excludeApps` | 通知を出さないアプリの名前 |
| `ui.animations` | パネルが出るときと消えるときにフェードするか |
| `ui.animationSeconds` | フェードの長さ（秒） |

## 開発

C#（.NET 8）で書いています。OpenVRは`third_party\openvr`（v2.15.6）、描画はSkiaSharpとDirect3D11（Vortice）、音量はNAudioを使います。ソースは`src\`にあり、変更したら`build.bat`で`app\`を作り直します。ビルドには.NET 8 SDKが要ります。リポジトリには`app\`が入っていないので、取ってきたら最初に`build.bat`を実行します。`app\GodanOverlay.exe --preview <出力フォルダ>`を実行すると、VRなしで各パネルの見た目をPNGに書き出せます。
